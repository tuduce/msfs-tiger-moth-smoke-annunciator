# Tiger Moth smoke annunciator (MSFS 2020)

A worn, vintage 60 × 30 × 15 mm annunciator box for the rear cockpit of Ant's Airplanes Tiger Moth, for use with PaulWalkerUK's
[Tiger Moth Aerobatic Smoke](https://github.com/PaulWalkerUK/msfs-tiger-moth-aerobatic-smoke) addon (v1.1.0):

* a **red, white and blue lamp** that light with the matching smoke (`A:SMOKE ENABLE:4/5/6`);
* a **LONG / SHORT toggle** for the smoke intensity - it drives the addon's own *Toggle G Limiter* control and shows its live state.

Everything is generated by script: the 3D model and its chipped-paint textures come from headless Blender, a merge step adds the model
to the interior glTFs of the installed Ants Tiger Moth, and the result is packaged for the Community folder.

```powershell
.\scripts\build.ps1 -Preview           # Blender build + merge + SDK package (add -NoSdkTool while MSFS is running)
.\scripts\install.ps1                  # copy to Community   (-Uninstall removes it)
```

Requirements: MSFS 2020 + SDK, Blender 3.6 with the MSFS 2020 glTF exporter addon, Python 3, the Ants Tiger Moth and the smoke addon
installed. After every install **restart MSFS completely** (reloading the aircraft keeps the old model cached).

See **[docs/GUIDE.md](docs/GUIDE.md)** for how it works, how to move the box, tune the lamps and test in the sim.

**Not included on purpose:** no file from the Ants Tiger Moth is stored here. `build.ps1` reads your installed copy and writes derived
files (patched `AntsTigerMoth_int.xml`, merged interior glTFs) only into your local working tree, where `.gitignore` excludes them.
Do not redistribute the built package.
